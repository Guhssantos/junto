# Segurança

Encontrou uma falha de segurança (ex.: ver dados de uma lista da qual não participa, contornar permissões, expor fotos privadas)?

**Não abra uma issue pública.** Use o relato privado do GitHub:
[Security → Report a vulnerability](https://github.com/Guhssantos/junto/security/advisories/new).

Inclua os passos para reproduzir e o impacto. Responderemos assim que possível e daremos o crédito pela descoberta, se você quiser.

Como o projeto protege os dados: [docs/SEGURANCA.md](docs/SEGURANCA.md).
